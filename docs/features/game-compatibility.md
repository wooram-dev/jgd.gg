# 게임 성향·궁합 v1

문서 책임: 게임 성향 질문, 16유형 분류, 유형 비교와 수락 기준.

## 범위

2026-09-18 사용자의 MBTI 같은 성향 분류 요청을 반영한다. `/게임궁합`은 로그인 없이 12개 질문에 답해 자신의 게임 성향을 확인하고, 친구가 알려준 유형을 선택해 비교하는 공개 라운지 콘텐츠다. MBTI의 문항·유형을 사용하지 않는 JGD.GG 자체 콘텐츠이며, 재미로 보는 게임 취향이라는 안내를 제공한다.

## 네 가지 축과 산식

| 순서 | 축 | 첫 번째 성향 | 두 번째 성향 |
|---|---|---|---|
| 1 | 플레이 목표 | R · 승부형 (승리·기록) | F · 즐김형 (과정·재미) |
| 2 | 문제 해결 | P · 계획형 (준비·전략) | I · 즉흥형 (시도·발견) |
| 3 | 플레이 호흡 | T · 합류형 (같은 목표로 함께) | S · 자율형 (각자의 역할·속도) |
| 4 | 대화 스타일 | V · 수다형 (말하며 즐기기) | Q · 집중형 (필요할 때 간결하게) |

각 축에 3문항, 문항당 양자택일로 총 12문항이다. 더 가까운 선택지를 고른다. 첫 선택은 첫 성향, 두 번째 선택은 두 번째 성향에 1표다. 축별 2표 이상인 성향을 선택해 순서대로 네 글자를 만든다. 홀수 문항이므로 동점은 없다. 무응답·잘못된 값·12개가 아닌 답변으로 결과를 만들지 않는다. 각 축은 몇 개의 답변이 해당 성향에 가까웠는지 `2/3` 또는 `3/3`으로 설명한다.

유형은 `R/F × P/I × T/S × V/Q`의 16조합이다. 각 유형에는 고유한 별명과 짧은 설명을 제공한다. 축·질문·유형 문구의 단일 구현 위치는 `src/features/game-compatibility/domain/compatibility.ts`다. 점수는 실력·성격·관계의 적합도를 예측하지 않는다.

## 사용자 흐름

1. 홈 카드 또는 공통 메뉴에서 진입한다. 시작 전 12문항·로그인 불필요·재미로 보는 취향·새로고침 시 초기화를 안내한다.
2. 한 번에 한 문항을 표시한다. 전체 12문항 중 현재 위치와 응답 수를 보여주며 선택 전에는 다음으로 진행할 수 없다. 이전 문항으로 돌아가 답변을 수정할 수 있다.
3. 마지막 응답 후 유형 코드·별명·설명과 네 축의 선택 근거를 보여주고 결과 제목으로 focus를 이동한다.
4. 친구의 유형을 16개 선택지에서 고르면 같은 축과 다른 축, 함께 플레이하기 전에 나눌 대화 제안을 표시한다. 미선택 시 비교 결과를 만들지 않는다. 동일 유형도 비교할 수 있다.
5. 궁합은 같은 성향의 개수(0~4)로 설명한다. 좋고 나쁜 궁합 순위·성공 확률·권장 또는 비권장 친구를 만들지 않는다. 다른 성향도 함께할 때 정할 수 있는 구체적 행동을 제안한다.
6. 자신의 유형 또는 친구와의 비교 요약을 클릭으로 복사한다. 실패 시 직접 선택할 텍스트를 제공한다. 복사 처리 중 편집·초기화·친구 변경을 잠가 이전 결과의 성공 표시가 새 결과에 남지 않도록 한다.
7. 답변 수정은 기존 답을 유지한 채 첫 질문으로 이동한다. 이전 결과·친구 선택·복사 상태는 지운다. 처음부터 다시 시작하면 답변도 모두 지운다.

## 데이터·역할 경계

질문 응답·유형·친구 선택은 현재 페이지의 React 메모리에서만 처리한다. API·DB·localStorage·sessionStorage·URL에 저장하지 않는다. 사용자가 복사한 내용은 직접 공유할 수 있다. 계정 이름·ID를 입력받지 않고 기존 게임 프로필을 읽지 않는다.

Discord bot·guild 설정과 Steam API가 필요하지 않다. 기존 봇의 `/스팀_비교`와 멤버 전용 게임 프로필은 유지한다. 웹의 메시지 자동 전송·계정 연결·매칭·서버 저장·포인트 적립·초대 링크는 비범위다. 게임 프로필 멤버 검사 설정은 사용자의 지시대로 추후 작업으로 둔다.

## Acceptance Criteria

- GC-1: 비로그인 상태에서 시작→12문항→유형→친구 비교→수정→초기화를 완료한다.
- GC-2: 무응답·잘못된 값으로 결과를 만들지 않는다. 이전/다음 이동 시 답변을 보존한다.
- GC-3: 16조합·축별 다수결·2/3 및 3/3 근거·결정성을 검증한다.
- GC-4: 모든 유형 쌍의 동일·다른 축 합은 4이며 비교 순서를 바꿔도 일치 수는 같다. 같은 유형과 정반대 유형도 비교한다.
- GC-5: 답변 수정·초기화·친구 변경 후 이전 비교·복사 상태가 남지 않는다. 복사 성공·실패와 처리 중 중복 입력을 검증한다.
- GC-6: 응답·유형·친구 선택을 네트워크·영구 저장소·URL로 보내지 않는다. 새로고침 시 초기화된다.
- GC-7: native radio·label·fieldset·legend, 단계·결과 focus, 복사 상태 안내와 키보드 조작을 제공한다. 320·390·1280px에서 가로 넘침이 없다.
- GC-8: 홈·desktop/mobile 메뉴 진입, 현재 메뉴 표시, 한글 주소 직접 진입·새로고침이 동작한다.
