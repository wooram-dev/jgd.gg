# 멤버 사진 스토리

홈 상단 환영 배너를 사진 스토리로 교체한다. 실제로 게시된 스토리만 목록에 표시한다.

## 동작

- 목록은 비로그인 방문자에게도 같은 배치로 공개한다. 실제 사진 열람은 Discord 로그인 사용자만 가능하다. ACTIVE 사용자만 게시하며 BANNED 작성자의 스토리는 숨긴다.
- 사진 한 장을 선택하고 미리보기를 확인한 뒤 게시한다. 목록에는 게시한 사진 대신 작성자의 원형 Discord 프로필 사진, 이름과 게시 경과 시간을 표시한다. 프로필이 없거나 로드에 실패하면 이름 첫 글자를 표시한다.
- 비로그인 상태에서 스토리 또는 내 스토리 추가를 누르면 로그인 안내 dialog와 로그인하기 버튼을 제공한다. 클릭 전에는 로그인 팝업을 띄우지 않고 스토리 사진도 요청하지 않는다. Escape·닫기로 목록의 원래 버튼에 돌아간다.
- 작성자당 프로필을 하나만 표시하고 그 작성자의 사진을 게시 시각 오름차순으로 묶는다. 이름이나 아바타가 같은 다른 계정은 합치지 않는다. 프로필을 누르면 아직 확인하지 않은 첫 사진부터, 모두 확인했다면 첫 사진부터 재생한다. 확인한 표시는 현재 화면 메모리에만 유지한다.
- 사진을 누르면 전체 화면에 가까운 dialog로 열고 사진 로드 완료 후 5초마다 다음 사진으로 넘어간다. 작성자의 마지막 사진 다음에는 현재 불러온 다음 작성자로 이동하며, 마지막 작성자까지 끝나면 닫는다. 상단에 작성자별 사진 수에 맞는 진행 막대를 표시한다.
- 사진의 왼쪽 절반을 누르면 이전 사진, 오른쪽 절반을 누르면 다음 사진이다. 방향키로도 이동하며 수동 이동 후에는 새 사진의 5초를 다시 센다. 전체 첫 사진의 이전 버튼은 비활성화하고 전체 마지막의 다음 버튼은 닫는다.
- 일시정지·재생을 제공하고 탭이 숨겨지면 시간을 멈춘다. 사진 로딩 중·로드 오류에는 자동으로 넘기지 않고 수동 이동·닫기는 유지한다.
- 서버 게시 시각부터 정확히 24시간 동안 열람한다. 만료 시 열린 화면에서도 사진을 제거하며 목록과 이미지 API는 만료된 사진을 반환하지 않는다.
- **24시간 후 삭제하지 않고 숨긴다. 원본은 서버에 계속 보관한다.** 별도 보관함이나 원본 다운로드 API는 제공하지 않는다. 원본 삭제 문의와 계정 삭제 처리 규칙은 [AUTH.md](../AUTH.md)를 따른다.
- JPEG, PNG, WebP 정지 사진만 받는다. 파일당 최대 5MiB, 디코딩 최대 4천만 픽셀, 사용자당 직전 24시간 내 최대 10장이다.
- 재전송은 같은 게시 키로 중복 저장을 막는다. 처음 수락한 사진과 만료 시각을 유지한다.
- 초기 목록은 작성자별 최신 사진 순 30명이고 더 보기로 이어진다. 각 작성자의 유효 사진 전체를 같은 페이지에 포함해 사진이 페이지 경계에서 잘리지 않는다. 새 게시 후와 탭 복귀 시 목록을 다시 조회한다.
- 스토리 외의 대화 주제, 기록, 미니게임은 기존 홈 위치와 동작을 유지한다.

## Acceptance Criteria

- [ ] 비로그인도 동일한 프로필 목록을 보고 클릭 시 로그인 팝업을 본다. 사진·썸네일·게시 API는 계속 인증을 요구한다.
- [ ] 로그인 여부와 관계없이 목록에는 게시자의 프로필 사진을 표시하고 로드 실패 시 이름 첫 글자로 대체한다.
- [ ] 한 작성자의 여러 사진은 프로필 하나에 묶이고 페이지 경계·동일 이름에도 누락·중복되지 않는다.
- [ ] 사진 로드 후 5초 자동 전환, 진행 막대, 좌우 클릭·방향키, 수동 이동 타이머 초기화와 마지막 닫기가 동작한다.
- [ ] 일시정지·숨겨진 탭·이미지 로딩·오류 중에는 자동으로 넘기지 않는다.
- [ ] 사진 선택·미리보기·게시·목록 반영·사진 열람이 desktop/mobile/320px에서 동작한다.
- [ ] 같은 게시 요청의 순차·동시 재전송이 한 장이며 롤링 24시간 게시 한도를 넘지 않는다.
- [ ] 만료 직전은 열람 가능하고 정확한 만료 경계부터 목록·이미지·열린 뷰어에서 숨긴다.
- [ ] 만료 후 원본 byte는 유지되고 사용자 삭제 시 cascade된다.
- [ ] 실제 파일 검증, 크기·픽셀 제한, Origin과 계정 상태 검사가 동작한다.
- [ ] 원본 보관 고지, 빈 상태·조회 실패·게시 실패 재시도, dialog focus 복구와 Escape 닫기를 제공한다.

검증 매핑: `image.test.ts`는 이미지/크기 검증, `story-strip.test.tsx`는 상태·재시도·만료 UI, `stories.integration.test.ts`는 권한·보존·동시성·DB 제약, `tests/e2e/stories.spec.ts`는 실제 게시·열람 흐름을 담당한다.
